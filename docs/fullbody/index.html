01アバターとカメラ

VRM 0.x / 1.0対応。モデルと映像は端末内で処理します。

配信用ウィンドウとPNGにも同じ向きで反映します。

02キャリブレーション

3秒後に測定を始めます（通常1.5秒、処理が遅い場合は延長）。カメラの位置を変えたら測り直してください。

未調整 · まずは初期値で動かせます

まぶたの感度を調整

「開く値」以上で全開、「閉じる値」以下で閉眼になります。左右は自分の体の左右です。

03動きと表情

着席モードは脚を休止します。手と顔・肩が映っていれば、肘が隠れても腕の位置を補います。

詳細設定

カメラ映像には検出した手指の骨格を表示します。検出時間が長い場合は軽量モードを選んでください。遠距離では顔や指の精度が下がります。隠れた関節は短く保持してから自然な待機姿勢に戻ります。

04表情と口

笑顔・眉を寄せた顔・目を見開いた顔を反映します。強すぎる表情は個別に弱められます。

口の形（カメラから推定）

「い・え」は横への広がりと開き、「う・お」はすぼめ方と開きから推定します。正面の記録は口を自然に閉じて行ってください。

05配信と背景

OBSは「ウィンドウキャプチャ」で配信用ウィンドウを選択。背景にグリーンを選び、クロマキーで透過します。透過PNGも保存できます。

配信用ウィンドウに操作パネルやカメラ映像は表示されません。メイン画面を開いたまま使ってください。
