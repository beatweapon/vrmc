# 共通サンプルVRM

`/models/`（`index.html`）にプレビュー、全身版への選択リンク、ダウンロードリンクを置く。ページを開くだけではカメラを起動しない。モデルのバイナリは選択・ダウンロードしたときにだけ取得する。

- `catalog.js`: 共通一覧。安定したID、名前、URL、作者、埋め込み利用条件を定義する。URLはモジュール基準で解決するため、Full Body・従来版・Partyのどこからでもimportでき、サブディレクトリへの公開にも対応する。
- `samples/`: 追加の13体と、VRMに埋め込まれたサムネイルをそのまま抽出したPNG。VRM本体は変更していない。
- `VRM1_Constraint_Twist_Sample.vrm`: 既存の標準モデル。従来版や既存リンクとの互換性のためパスを維持する。

全身版の設定からサンプルを切り替えると、既存のアップロードと同じFile保存・配信出力処理を通る。再読み込み時も選択を復元する。`fullbody/?settings=1&sample=g`のようなリンクは選択成功後にsampleパラメータを除き、その後の手動選択を再読み込みで上書きしない。取得・解析に失敗した場合は現在のモデルを維持する。

他の画面へ選択UIを追加する場合は、この一覧をimportし、既存のモデル読込へ`url`または`sampleFile(id)`を渡す。モデルを画面ごとに複製しない。今回は従来版・Partyの追跡や選択UIは変更していない。ダウンロード後のファイル読込は従来どおり利用できる。

利用条件はファイル内のVRMメタ情報を表示している。追加13体には`avatarPermission: onlyAuthor`、`allowRedistribution: false`、`modification: prohibited`等が記録されている。表示は許諾の追加・変更ではない。メタ情報の上書きは行わない。

`npm run test:samples`で全13体の実読み込み、保存・再読込、配信出力、取得失敗時のモデル維持、標準モデルへの復帰、ダウンロードのバイト一致を確認する。カメラは使用しない。
