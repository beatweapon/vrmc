VRMCとOBSでオンライン会議する方法

VRMC fullbody とOBSの仮想カメラを使うと、VRMアバターをGoogle Meet、Zoom、Microsoft Teamsなどのカメラ映像として使えます。

  1. VRMC fullbodyをアプリとしてインストールする

    Chromeで VRMC fullbody を開き、アドレスバーに表示されるインストールボタンからアプリとしてインストールします。

    インストール後にタスクバーやDockへ置いておくと、普段使っているブラウザのウィンドウやタブと混ざらないので便利です。

  2. 会議向けのトラッキングモードを選ぶ

    設定画面の「トラッキングモード」から、用途に合わせて Full Body または Face Only を選びます。

    • Full Body：顔・体・手指を追跡します。手振りや姿勢も見せたいときに向いています。
    • Face Only：顔だけを追跡し、体・手の追跡処理を止めます。会議中の負荷を抑えたいときに向いています。

    OBSやZoomなどを同時に使って重く感じる場合は、配信画面右下の羽アイコンから軽量モードをONにしてください。追跡・描画の負荷をまとめて下げられます。

  3. OBSでVRMC fullbodyをウィンドウキャプチャする

    VRMC fullbodyのウィンドウを開いた状態でOBSを起動します。

    OBSの「ソース」パネルにある「＋」をクリックして「ウィンドウキャプチャ」を追加し、キャプチャするウィンドウとしてアバターを表示しているVRMC fullbodyを選択します。

  4. OBSの仮想カメラを起動する

    OBSの「仮想カメラ開始」をクリックします。

  5. 会議ツールでOBS Virtual Cameraを選ぶ

    会議ツールのカメラ設定を開き、「OBS Virtual Camera」を選択します。これでVRMアバターをカメラ映像として使えます。

自分だけのアバターを作りたい場合

オリジナルのVRMアバターを作りたい場合は、無料で使える VRoid Studio がおすすめです。作成したVRMファイルをVRMC fullbodyへ読み込めば、そのまま会議用アバターとして使えます。

Chromeが既定で使うカメラを変更したい場合

Chromeのカメラ設定は chrome://settings/content/camera から変更できます。

Chromeの仕様により、このページから chrome:// のリンクを直接開けない場合があります。その場合は chrome://settings/content/camera をコピーしてChromeのアドレスバーに貼り付けてください。
